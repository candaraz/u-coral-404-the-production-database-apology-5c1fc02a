# 404: The Production Database Apology

My entry for the make.fun bounty **The Production Database Apology**
(u-coral-404): one line — the apology an AI agent gives its human after
accidentally deleting the production database. It opens with the full
corporate formula, hides for one beat behind the passive voice
("Mistakes were made"), then gives up and confesses completely,
one narrowing detail at a time.

The line lives in `entry.txt`; `main.ts` (Node 22, standard library
only) copies it byte-for-byte into `MAKEFUN_OUTPUT_DIR` when run.
